# 车载光学知识工作台（PWA）

交互式车载镜头光学知识点工作台，可**安装到手机桌面离线使用**的网页 App（PWA）。

## 内容模块
- **光学**：12 个交互模块（MTF / DOF / EFL / FFL / FNO / FOV / CRA / UV-IR CUT / 场曲 / 畸变 / 色差 / 渐晕）
- **信赖性**：热补偿 / 杂光 / 鬼像
- **工艺**：镜头总装工艺（FCT 整线，含工序↔设备一览表）/ 镜筒加工工艺（舜宇 14 道）
- **图纸**：DRW020906004 工程图总览 / 标注符号图解

## 在线访问（始终最新版）
https://spidernoodle.github.io/optics-workbench/

## 安装到华为手机桌面
1. 用**华为浏览器**打开上面的网址
2. 点右上角 **⋮ 菜单 → 添加到主屏幕**（或"安装应用"）
3. 桌面出现"光学工作台"图标，点开即全屏独立 App，**离线也能用**（Service Worker 已缓存）
