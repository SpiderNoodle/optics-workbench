释义：MTF（Modulation Transfer Function，调制传递函数）衡量光学系统还原图像对比度的能力——数值越高，越能保留细密细节。它是镜头"清晰度"的量化指标，直接决定远处车牌、条码能否被看清。

MTF 曲线：横轴=细节粗细（lp/mm），纵轴=还剩多少对比度
类比：镜头像一套音响的频率响应。低音（大块特征）轻松过关，高音（细密条纹）会被削掉。MTF 就是"光学系统的频率响应曲线"——曲线掉得越狠，越怕细节。车载镜头要在远处把车牌读清楚，拼的就是高频段 MTF 还不能趴下。拖一下"镜头锐度"，看大字还能认、细条码怎么先糊掉。
释义：DOF（Depth of Field，景深）是对焦平面前后仍能保持可接受的清晰成像的纵深范围。景深越大，远近物体越能同框清晰；它随光圈缩小而增大，随焦距、拍摄距离变化。

DOF = 对焦平面前后，还有多大一片是清楚的

类比：光圈像瞳孔。瞳孔放大（小 F 数），只有正对焦那一点清楚，前后全虚——背景虚化就这么来的；瞳孔缩小（大 F 数），前后一大片都清楚。前视摄像头要"远近都看清"，常用小光圈、大景深。
释义：EFL（Effective Focal Length，有效焦距）是镜头将无限远平行光汇聚到焦点的等效距离，决定视角大小与放大倍率：EFL 越小视角越广（左右都收得进画面），越大越远摄（把远处目标拉得越大）。

EFL = 镜头的"望远镜倍率"，直接决定能看到多宽、多远

类比：EFL 是镜头的变焦档位。数值小=广角，左右都能收进画面（环视/盲区监测爱用）；数值大=长焦，把远处车子拉得很近很大（前视看远、认车牌爱用）。EFL 越大，视角越窄、远处目标越大。
释义：FFL（Flange Focal Length，法兰焦距）是镜头卡口基准面到传感器成像平面的机械距离，是机身定死的规格（如 C 卡口 17.5mm、CS 卡口 12.5mm）。它决定"无限远能否合焦"——差 0.x mm 都会废掉远焦档。

FFL = 机身里"镜头卡口到传感器"的固定距离，相当于传感器该坐的座位深度

是什么：FFL 是镜头卡口基准面到传感器平面的机械距离，是机身定死的规格（例如工业 C 卡口 17.5mm、CS 卡口 12.5mm，车载模组也各有标定值）。镜头是按这个深度设计的。
为什么重要：来自无限远的平行光，经过镜头后必须恰好汇聚在传感器上才能"无限远清晰对焦"。座位刚好（绿）→ 汇聚成一点；坐歪了（红）→ 光在传感器上还是一团 → 无限远永远对不上焦。
和调焦环的关系：你拧调焦环，是让镜片组前后移动、改变汇聚点，用来补偿近处物体的对焦；但只要 FFL 本身不对，无限远这一档就废了。所以换镜头/模组，FFL 必须严丝合缝（差 0.x mm 都不行）。
释义：场曲（Field Curvature）指理想像面本应是平面，但实际镜头形成的清晰像面常呈弯曲（碗状）。平面传感器只能与碗壁相切于某一圈，因此中心清楚时边缘虚、边缘清楚时中心虚，无法整幅同时清晰。

场曲 = 真实镜头形成的"像面"是弯的（像碗），平面传感器只能蹭到其中一圈清楚

类比：清晰像其实形成在一只浅碗的内壁上。而传感器是平板，只能和碗壁相切于某一圈——中心清楚时边缘虚，边缘清楚时中心虚，怎么对焦都救不回整幅。这就是场曲（Field Curvature）。广角镜头（车载环视常用）场曲更明显，所以画面四角常偏软；设计师加"场曲校正镜组 / 平场镜"把它压平。
释义：畸变（Distortion）是镜头对不同视场的放大率不一致，使直线变弯：中心放大更多呈桶形、边缘放大更多呈枕形。它不损失清晰度，只是像素移位，可由 ISP 用标定参数校正。

畸变 = 镜头把直线拍弯：桶形（向外鼓）或枕形（向内凹），但像素没丢、只是移位

注意畸变不改变清晰度，只是把图像像橡皮一样拉伸：中心放大得多→桶形（鱼眼/广角常见）；边缘放大得多→枕形（长焦/变焦端常见）。车载广角镜头多带桶形畸变，但没关系——ISP 里用标定参数就能把它"掰直"，所以你看到的最终画面是方的。
释义：色差（Chromatic Aberration）源于不同波长的光折射率不同，无法汇聚于同一点：蓝光的像比红光的像更靠近镜头（轴向色差），或放大倍率不同（倍率色差）。结果就是亮暗边缘镶上一圈红/蓝彩边。

色差 = 玻璃对红/绿/蓝折弯程度不同，白边会镶上红蓝彩边

原理：同一块玻璃，蓝光的折射率比红光大，所以蓝像比红像更靠近镜头（轴向色差），或放大倍率不同（倍率色差）。结果就是亮暗边缘镶上一圈红/蓝。车牌的白边会泛彩边，机器读起来更费劲。修法：用低色散玻璃（ED）、胶合消色差双片把几条色光对齐。
释义：渐晕（Vignetting）是画面边缘相对中心亮度衰减的现象。成因有二：几何上斜射光按 cos⁴θ 定律衰减（视角越大衰越多），机械上镜筒/镜片边缘也会遮挡部分斜光。

渐晕 = 画面四角比中心暗，越广角的镜头越明显

成因有两层：几何上斜射光按 cos⁴θ 定律衰减（视角越大衰越多），机械上镜筒/镜片边缘也会挡掉部分斜光。车载广角前视/环视镜头四角容易偏暗，ISP 要做亮度均一化（shading correction）把边角提亮，否则边角一放大增益就噪点暴涨。
释义：工艺（制造工艺流程）是把光学设计变成可量产镜头的工序序列——从「来料检验」到「自动组装、点胶锁付、可靠性老化」，再到「MTF / 杂光 / 偏心等光学检验」，最后「真空包装出货」。它保证每一个镜头都达到设计约定的光学指标（前面光学部分讲的概念，正是这里被逐道"打卡"的对象）。
FCT 车载镜头制造工艺流程（依据 FCT-PFD.pdf · PFD-SF816BJ-01）
逐道工序详解
1 来料检验 Incoming Inspection · JY010–JY050
工序：来料接收 → 来料报检 → 零部件入库 → 零部件发料 → 物料接收。
核对内容：镜片（外径 14 / 11.8 -0.01/-0.002；中厚 胶合件 4.68、镜片四 3.78、镜片五 0.9；矢高 镜片七 S1 0.902、镜片六 S2 0.698；镀膜反射率 R(max)≤0.3~0.5% @420–680nm、≤1.0% @410–690nm）、镜筒（材质 ADC12、ROHS；亚光发黑层 5–15μm、1000h UV 不变色、60°光泽≤2GU；镭雕+铬酸盐钝化、电阻≤5Ω、孔隙率≤2.5%）、隔圈（拦光口径 φ8.1±0.03、中厚 0.579±0.005）。
为什么关键：来料是后续所有光学指标的"地基"——尺寸或镀膜不达标，后面组装再好也救不回 MTF。
2 镜筒加工 Barrel Machining · FZ010–FZ050
工序：镜筒打标（追溯码） → 镜筒吹拭（除尘） → 摆盘 / 取料 → 集尘。
设备：摆盘机、集尘器。
内容：镜筒清洁、激光打标建立追溯、除尘，确保组装前镜筒无尘无污。
为什么关键：镜筒洁净度直接影响组装后的内尘与杂散光（见 渐晕 / 杂光）。
3 自动组装 Automatic Assembly · ZZ010–ZZ090
工序：部品排料 → 外压圈锁付（锁付机） → IR 组立点胶曝光（一体机） → 外压圈点胶曝光（单工站） → 自动内尘检查（内尘设备） → 一道 MTF 检查（逆光路设备） → 吸塑包材喷淋清洗。
设备：组装机、外压圈锁付机、IR 组立点胶一体机、外压圈点胶单工站、自动内尘设备。
内容：按设计次序将镜片、隔圈、IR 滤色片装入镜筒并点胶锁付固定，形成完整镜头。
为什么关键：组装顺序 / 点胶量 / 锁付力矩决定镜片间隔与偏心，是 MTF、场曲、畸变、偏心 的源头。
4 过程光学检验 · 一道 MTF In-process Optical Check · 逆光路设备
内容：组装后立即用逆光路法测一道 MTF，并与内尘检查联动。
验证：MTF 119lp/mm：0°≥0.50 / 4.5°≥0.45 / 8.6°≥0.38 / 12°≥0.35；DOF ≥10µm。
为什么关键：第一道光学体检，组装偏倚在此暴露，不合格直接返工 / 隔离。
5 可靠性预处理 Reliability · ZZ100–ZZ120
工序：温度预处理（老化箱） → 高温烘烤（烘箱） → 老化（两循环共 16H）。
老化温区：25℃→-43℃(30min) → 恒 -43℃(240min) → 升 95℃(30min) → 恒 95℃(120min) → 降 -43℃(30min) → 回 25℃(30min)，共 2 循环 16H。
为什么关键：模拟车载极端冷热冲击，把虚焊 / 应力松动逼出来，确保镜头在考验后光学指标仍稳。
6 二道 MTF 检查 2nd MTF Inspection · PRO10
设备：PRO10。
内容：老化后复测 MTF / 场曲 / 畸变 / DOF，确认可靠性考验后指标不退化。
验证：MTF 同前；场曲 4.5°/8.6°/12° ≤±10µm；像面倾斜 ≤0.25°；畸变 (-2.7±1)% @DFOV；DOF ≥10µm。
为什么关键：老化后的"终检预演"，把温度应力引入的指标漂移挡在门外。
7 最终检验 Final Inspection · BZ010–BZ030 / CC010
工序：干冰清洗（干冰设备） → VGI 检查（VGI 设备） → 杂光检查（自动杂光设备） → 偏心检查（自动偏心设备） → 二道外观检查。
验证：VGI (ISO18844) <2.0%；杂光 对比杂光封样判定（与 渐晕 / 杂光 相关）；偏心 ≤0.3°；二道外观：表面与缺陷封样对比。
为什么关键：出厂前最后一道全员体检，把 MTF / 场曲 / 畸变 / 偏心 / 杂光 / VGI 一次性收口。
8 包装出货 Packaging & Shipment · ZZ090 / WG010 / QJ010
工序：真空包装（真空包装机） → 成品包装 → 完工检验 → 产品出货（成品接收入库）。
内容：镜头满足客户端接口要求后，真空防潮包装、完工检验、入库出货。
为什么关键：封箱前确认"镜头满足客户端接口要求"，交付即放行。
质量关口对照——前面 8 个概念如何被验证
一道 / 二道 MTF 检查 → 验证 MTF（119 lp/mm：0°≥0.50 / 4.5°≥0.45 / 8.6°≥0.38 / 12°≥0.35）、场曲（4.5°/8.6°/12° ≤±10µm）、畸变（(-2.7±1)% @DFOV）、DOF（≥10µm）。
杂光检查 → 控制杂散光 / 鬼影（与渐晕、杂光相关），VGI（ISO18844）<2.0%。
偏心检查 → 偏心 ≤0.3°；二道外观 / VGI → 表面与眩光达标。
设计指标正是在每一道工序里被"打卡"。工艺，就是把抽象的光学概念变成可量产、可检验的实物。
