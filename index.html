释义：MTF（Modulation Transfer Function，调制传递函数）衡量镜头还原"黑白相间细密条纹"对比度的能力——数值越高细节保留越好，远处车牌 / 条码越读得清。它是镜头"清晰度"的量化指标。
单位 lp/mm（line pairs / 毫米，线对每毫米）：把"一条黑线 + 一条白线"算 1 个线对，lp/mm 表示每毫米能分清多少个明暗周期。数值越大 = 能分辨越细的条纹。车载 spec 要求 119 lp/mm 处仍有足够 MTF（中心 ≥0.50、边缘 ≥0.35）。
两条曲线（T / S）：MTF 是"方向相关"的。子午（T，tangential / meridional，过圆心放射状方向）与弧矢（S，sagittal，垂直子午的同心圆切线方向）要分别画曲线。通常 S 略优于 T，好镜头要求 T、S 贴合。
轴上 / 离轴：还要分视场——中心（0°）MTF 最好，越往边缘（0.7 / 1.0 视场）越掉。spec 的 "0°≥0.50 / 4.5°≥0.45 / 8.6°≥0.38 / 12°≥0.35" 就是不同视场的要求。
天花板 = 衍射极限：任何镜头 MTF 都不可能超过"理想衍射极限"（由波长 λ 与光圈 F 决定），实际镜头只能逼近它。

MTF = 镜头留住多少"黑白对比"，越细的条纹（高 lp/mm）越容易丢；子午 T、弧矢 S 各一条

类比：镜头像一套音响的频率响应。大块特征（低频、粗条纹）轻松过关，细密条纹（高频、高 lp/mm）会被削。MTF 曲线就是"光学频率响应"——掉得越狠越怕细节。车载镜头要在远处把车牌读清，拼的是高 lp/mm 段 MTF 还不能趴下。拖"镜头素质"看细条码怎么先糊，拖"考察视场"看边缘怎么比中心掉得快。
释义：DOF（Depth of Field，景深）是对焦平面前后仍能保持可接受的清晰成像的纵深范围。景深越大，远近物体越能同框清晰；它随光圈缩小而增大，随焦距、拍摄距离变化。

DOF = 对焦平面前后，还有多大一片是清楚的

类比：光圈像瞳孔。瞳孔放大（小 F 数），只有正对焦那一点清楚，前后全虚——背景虚化就这么来的；瞳孔缩小（大 F 数），前后一大片都清楚。前视摄像头要"远近都看清"，常用小光圈、大景深。
释义：FNO（F-number / F 数）= 焦距 ÷ 入瞳直径，是镜头的"光圈档位"。F 越小=光圈越大=进光越多，但景深越浅、像差越敏感；F 越大=光圈越小=进光越少，但景深越深、衍射越严重。F 数同时挂进光量、景深、衍射极限、杂光、信噪比五项，是镜头最重要的"音量旋钮"。

F 越小孔越大：进光多 / 景深浅 / 像差敏感；F 越大孔越小：进光少 / 景深深 / 衍射严重

对比：左侧 F=1.4 满光圈参考；右侧 = 你选的 F（孔径 4.67 ÷ F mm）
相对进光量（以 F=1.4 = 100% 为基准；照度 ∝ 1 / F²）
产品 spec：F.NO = 1.8 ±5%。车载镜头要兼顾暗光进光（F 不宜太大）+ 远近都清（F 不宜太小）+ 衍射不盖过像素（Airy 斑 ≤ 3×像素尺寸 ≈ 6µm），F=1.8 是这三项的折衷点。
释义：FOV（Field of View，视场角）是镜头朝前能看到的角度范围。分 HFOV 水平（左右看多宽）、VFOV 垂直（上下看多高）、DFOV 对角线（斜对角），三者由 焦距 EFL 与 传感器尺寸 共同决定：FOV = 2·arctan(尺寸 / 2EFL)。FOV 越大越"广角"（看得宽但远处小），越小越"长焦"（看得窄但拉得近）。

FOV = 镜头朝前能看到多宽，分水平 / 垂直 / 对角线三档

顶视示意图：车在左，视锥向右展开；扇形末端 = 前方 10m 处可见宽度
产品 spec：HFOV 100.5°±1.5° / VFOV 55.9°±1° / DFOV 116°±1.5°。FOV 越大，畸变、渐晕、边缘像质越难做——镜头要把畸变压到 -38.5%、RE-ILL≥79% 才能撑住这个宽视角。想看远，EFL 拉长、FOV 必然变窄。前视/环视/后视的差异就由 FOV 决定：前视要广（看路口），后视/识别要窄（拉车牌）。
释义：CRA（Chief Ray Angle，主光线角度）是到达像点的光线与传感器表面法线的夹角。视场越大（越靠边），CRA 越大。传感器每个像素上有个微透镜"小碗"，只收正面附近的光；CRA 太大，光就溢到隔壁像素（串扰），导致边角发暗、彩边、噪点。所以镜头 CRA 必须塞进 sensor 的 CRA budget（接受角）。

CRA = 光线打在 sensor 上的倾斜度；越斜越容易"串到邻居家碗里"

一排像素（带微透镜碗）：中心光正、边缘光斜；斜过接受角就溢出（红）
产品 spec：CRA = 19.6°±1.5° @HFOV。当 HFOV 达 100°，边缘像点 CRA 已逼近 sensor 接受极限；sensor 若提供 microlens tilt 或光线弯折能力才能匹配，否则边角发暗、彩边。CRA 是镜头与 sensor 厂之间的"接缝协议"。
释义：UV/IR CUT（双截止滤光片）是镜头最后一枚关键光学元件——同时截止紫外（<430nm）与红外（>680nm），只让可见光 430~680nm 通过。人眼看不见的红外，CMOS 会把它当亮度叠加到 RGB 上，导致色彩偏粉、对比失真；少了它，色彩还原基本失守。

UV/IR CUT = 把不可见光挡在门外，只让可见光进 sensor，色彩才不会"串味"

产品 spec：UV/IR CUT = 430nm±10nm / 680nm±10nm。光谱曲线不是"一刀切"——UV/IR 段衰减要陡，可见光段要透得平，否则色温、对比都会偏。装配时这枚滤片是贴 sensor 的那一片，盖上后镜头才算真正"完整"——少它，色彩不还原；错位，sensor 直接坏点。
释义：EFL（Effective Focal Length，有效焦距）是镜头将无限远平行光汇聚到焦点的等效距离，决定视角大小与放大倍率：EFL 越小视角越广（左右都收得进画面），越大越远摄（把远处目标拉得越大）。

EFL = 镜头的"望远镜倍率"，直接决定能看到多宽、多远

类比：EFL 是镜头的变焦档位。数值小=广角，左右都能收进画面（环视/盲区监测爱用）；数值大=长焦，把远处车子拉得很近很大（前视看远、认车牌爱用）。EFL 越大，视角越窄、远处目标越大。
释义：FFL（Flange Focal Length，法兰焦距）是镜头卡口基准面到传感器成像平面的机械距离，是机身定死的规格（如 C 卡口 17.5mm、CS 卡口 12.5mm）。它决定"无限远能否合焦"——差 0.x mm 都会废掉远焦档。

FFL = 机身里"镜头卡口到传感器"的固定距离，相当于传感器该坐的座位深度

是什么：FFL 是镜头卡口基准面到传感器平面的机械距离，是机身定死的规格（例如工业 C 卡口 17.5mm、CS 卡口 12.5mm，车载模组也各有标定值）。镜头是按这个深度设计的。
为什么重要：来自无限远的平行光，经过镜头后必须恰好汇聚在传感器上才能"无限远清晰对焦"。座位刚好（绿）→ 汇聚成一点；坐歪了（红）→ 光在传感器上还是一团 → 无限远永远对不上焦。
和调焦环的关系：你拧调焦环，是让镜片组前后移动、改变汇聚点，用来补偿近处物体的对焦；但只要 FFL 本身不对，无限远这一档就废了。所以换镜头/模组，FFL 必须严丝合缝（差 0.x mm 都不行）。
释义：场曲（Field Curvature）指理想像面本应是平面，但实际镜头形成的清晰像面常呈弯曲（碗状）。平面传感器只能与碗壁相切于某一圈，因此中心清楚时边缘虚、边缘清楚时中心虚，无法整幅同时清晰。

场曲 = 真实镜头形成的"像面"是弯的（像碗），平面传感器只能蹭到其中一圈清楚

类比：清晰像其实形成在一只浅碗的内壁上。而传感器是平板，只能和碗壁相切于某一圈——中心清楚时边缘虚，边缘清楚时中心虚，怎么对焦都救不回整幅。这就是场曲（Field Curvature）。广角镜头（车载环视常用）场曲更明显，所以画面四角常偏软；设计师加"场曲校正镜组 / 平场镜"把它压平。
释义：畸变（Distortion）是镜头对不同视场的放大率不一致，使直线变弯：中心放大更多呈桶形、边缘放大更多呈枕形。它不损失清晰度，只是像素移位，可由 ISP 用标定参数校正。

畸变 = 镜头把直线拍弯：桶形（向外鼓）或枕形（向内凹），但像素没丢、只是移位

注意畸变不改变清晰度，只是把图像像橡皮一样拉伸：中心放大得多→桶形（鱼眼/广角常见）；边缘放大得多→枕形（长焦/变焦端常见）。车载广角镜头多带桶形畸变，但没关系——ISP 里用标定参数就能把它"掰直"，所以你看到的最终画面是方的。
释义：色差（Chromatic Aberration）源于不同波长的光折射率不同，无法汇聚于同一点：蓝光的像比红光的像更靠近镜头（轴向色差），或放大倍率不同（倍率色差）。结果就是亮暗边缘镶上一圈红/蓝彩边。

色差 = 玻璃对红/绿/蓝折弯程度不同，白边会镶上红蓝彩边

原理：同一块玻璃，蓝光的折射率比红光大，所以蓝像比红像更靠近镜头（轴向色差），或放大倍率不同（倍率色差）。结果就是亮暗边缘镶上一圈红/蓝。车牌的白边会泛彩边，机器读起来更费劲。修法：用低色散玻璃（ED）、胶合消色差双片把几条色光对齐。
释义：渐晕（Vignetting）是画面边缘相对中心亮度衰减的现象。成因有二：几何上斜射光按 cos⁴θ 定律衰减（视角越大衰越多），机械上镜筒/镜片边缘也会遮挡部分斜光。它用 RE-ILL（相对照度 = 边角照度 / 中心照度 × 100%） 量化，spec 给的是边缘像高处的最低值。

渐晕 = 画面四角比中心暗，越广角的镜头越明显，用 RE-ILL 量化

成因有两层：几何上斜射光按 cos⁴θ 定律衰减（视角越大衰越多），机械上镜筒/镜片边缘也会挡掉部分斜光。车载广角前视/环视镜头四角容易偏暗，ISP 要做亮度均一化（shading correction）把边角提亮，否则边角一放大增益就噪点暴涨。spec 要求 RE-ILL ≥ 79% ±5% @HFOV，即 HFOV 边缘像点的照度不得低于中心的 79%——这条线是镜头与 ISP 之间的"分账协议"。
释义：热补偿（Thermal Compensation）指镜头 / 模组在 -40℃~105℃ 的车载温区内，通过 材料选择（CTE）+ 机械结构（浮动组 / 形状记忆合金）+ ISP 算法 三层叠加，主动抵消镜片热胀冷缩引起的像面偏移。它要同时满足：4 个温区合规（-40 / -20 / 25 / 85℃）、残余偏移 ≤ DOF、MTF 不掉档。

热补偿 = CTE × 温变 × EFL 算出来的温漂，靠结构+算法压回 DOF 内

横轴 = 温度（℃），纵轴 = 焦点偏移（µm）；绿带=DOF 容差、灰带=4 个温区背景、红线=无补偿漂移、绿线=补偿后
当前温度下，焦点在 sensor 平面上的位置（中间带 = DOF，绿=在带内清晰，红=跑焦）
算法：原始温漂 = CTE × ΔT × EFL × 标度（EFL=4.67mm）→ 残余 = 原始 × (1 - 结构补偿) × (1 - 算法补偿×0.5)。当残余落在 DOF 带内，中心 / 边缘 MTF 才不降档。4 个温区（-40 / -20 / 25 / 85℃）必须全绿才是真正过规格——只测 25℃ 的 lab 数据是骗自己。
类比：镜头像一把会热胀冷缩的尺子。CTE 是尺子的"脾气"（塑料脾气大、玻璃脾气小），结构补偿是"可伸缩的尺芯"（自动跟着温变微调），算法补偿是"事后对答案"（ISP 拿 MTF 反馈再对焦）。三层叠加，温漂被一压再压。
释义：杂光（Stray Light，杂散光）就是不该进镜头的那部分光。正常成像只需要"从目标直线射来的光"；但太阳、路灯、对向车灯、路面反光，甚至镜筒内壁，都会把光弹来弹去、散射后"溜"进传感器。这些乱入的光不像正常图像那样成像，而是在整幅画面上叠了一层均匀的灰白雾（veiling glare，遮光罩眩光）——它把黑电平整体抬高、对比度压低，暗处的行人、标线、车牌就被这层雾"吃掉"了。

一句话：杂光 = 强光的"溢光"像牛奶一样糊住整幅，对比度被整体拉低

为什么绕？——用纸筒打个比方。 把镜头想成一根两端开口、内壁没涂黑的纸筒。你对着太阳看，阳光从正面进来的同时，有一部分光会在纸筒内壁反复反弹、散射，最后从"侧面 / 背面"也溜达到了筒底的传感器上。这些"走后门"的光跟正经成像的光混在一起，画面就蒙上一层灰白雾——这就是杂光。夜里对向车灯一照，整屏泛白、暗处细节消失，正是这个原理。

怎么衡量、怎么修？ 用「杂光比 / VGI」衡量这层雾有多厚（工艺里要求 VGI<2.0%）。修法三板斧：① 镜筒内壁染黑消光；② 加遮光片（flare stop）挡住斜射杂光；③ 镜片镀低反射增透膜，让内壁少反弹。
释义：鬼像（Ghosting）是杂光的"点状版本"。当画面前方有很强的小光源（太阳、尾灯、路灯）时，这束强光会在相邻两片镜片之间反弹 1~2 次——相当于光在镜片之间"照了一次镜子"，最后在画面的另一个位置印出一个错位、发虚的亮斑或光环。它不像杂光那样糊整幅，而是固定位置的一个亮斑，跟着光源走、随亮度强弱变化。

一句话：鬼像 = 强光源在镜片间"照镜子"，在画面别处留下一个错位亮斑

杂光 vs 鬼像，一图分清： 杂光是"面"——一整层均匀白雾；鬼像是"点"——一个错位的亮斑。两者同源（都是乱入的杂散光），但杂光"散成一锅雾"，鬼像"聚成一个斑"。

通俗类比： 隔着几层玻璃窗看夕阳，窗玻璃会映出一个模糊的、偏移的太阳影子——那层模糊影子就是"鬼像"。它常出现在逆光行车、盯着夕阳看时，画面里凭空多一个柔光斑，很碍眼。修法跟杂光相通：镀多层增透膜压低镜片反射、优化镜片间距与曲率，让内部"照镜子"几乎不发生。
释义：镜头总装工艺是把镜片 / 镜筒 / 隔圈 / IR 滤色片等已经加工好的零部件，按光学设计顺序装配成完整镜头，并逐道验证光学指标（MTF / 场曲 / 畸变 / DOF / 杂光 / 偏心 / VGI）的整线流程。它不同于「镜筒加工工艺」——后者只负责把金属铝变成合规的镜筒壳体；总装是镜筒加工完成后的下游环节。

来料检验 Incoming Inspection · JY010–JY050 / FZ010–FZ020
检验镜片/镜筒/隔圈尺寸与镀膜，阻断不良毛坯
⌄
工序：来料接收 → 报检 → 零部件入库(JY040) → 发料(JY050) → 物料接收(FZ010) → 生产取料(FZ020)。
关键：来料是后续所有光学指标的"地基"——尺寸/镀膜不达标，后面组装再好也救不回 MTF。
2
镜筒加工 Barrel Machining · FZ030–FZ050
打标+吹拭除尘，确保组装前镜筒洁净
⌄
工序：镜筒打标(FZ030) → 吹拭(FZ040) → 部品排料(FZ050)。
关键：镜筒洁净度直接决定组装后的内尘与杂散光（见 渐晕/杂光）。
3
自动组装 Automatic Assembly · ZZ010–ZZ070
镜片入筒+点胶锁付，决定 MTF 与像质
⌄
工序：自动组装(ZZ010) → 外压圈锁付(ZZ020) → 自动内尘检查(ZZ030) → IR 组立点胶曝光(ZZ060) → 外压圈点胶曝光(ZZ070) → 吸塑包材喷淋清洗。
关键：组装顺序 / 点胶量 / 锁付力矩决定镜片间隔与偏心，是 MTF、场曲、畸变、偏心的源头。
4
过程光学检验·一道MTF In-process Optical Check · 逆光路设备
组装后立刻逆光路测 MTF，挡住偏心与内尘
⌄
内容：组装后立即用逆光路法测一道 MTF，并与内尘检查联动。
验证：MTF 119lp/mm：0°≥0.50 / 4.5°≥0.45 / 8.6°≥0.38 / 12°≥0.35；DOF ≥10µm。
关键：第一道光学体检，偏倚在此暴露，不合格直接返工/隔离。
一道 MTF：多视场曲线都要爬过橙色验收门槛（越高 = 越清晰）
5
可靠性预处理 Reliability · ZZ040 / ZZ080
冷热冲击 2 循环 16H，逼出虚焊松动
⌄
工序：温度预处理(ZZ040, 老化箱) → 高温烘烤(ZZ080, 烘箱)。
温区（单循环 480min × 2 = 16H）：25→-43℃(0–30min) → 恒-43℃(30–270min) → 升95℃(270–300min) → 恒95℃(300–420min) → 降-43℃(420–450min) → 回25℃(450–480min)。
关键：模拟车载极端冷热冲击，把虚焊 / 应力松动逼出来，确保考验后指标仍稳。
可靠性预处理：在 -43℃ ↔ 95℃ 间来回冲击，逼出虚焊 / 应力松动
6
二道 MTF 检查 2nd MTF Inspection · PRO10
老化后复测，确认指标不漂
⌄
内容：老化后复测 MTF / 场曲 / 畸变 / DOF，确认可靠性考验后指标不退化。
验证：MTF 同前；场曲 4.5°/8.6°/12° ≤±10µm；像面倾斜 ≤0.25°；畸变 (-2.7±1)%@DFOV；DOF ≥10µm。
关键：老化后的"终检预演"，把温度应力引入的指标漂移挡在门外。
二道 MTF：老化前后曲线几乎重合 = 指标不漂
7
最终检验 Final Inspection · QJ010 / ZZ100 / ZZ110 / ZZ120
杂光/偏心/VGI/外观最后收口
⌄
工序：干冰清洗(QJ010) → 偏心检查(ZZ100) → VGI 检查(ZZ110) → 杂光检查(ZZ120) → 二道外观。
验证：VGI (ISO18844)<2.0%；杂光 封样判定；偏心 ≤0.3°；外观按封样。
关键：出厂前最后收口，MTF/场曲/畸变/偏心/杂光/VGI 一次性收口。

逐道工序详解（关键控制 ★ 已标）
点击单卡标题可单独展开
1
来料检测 Incoming Inspection · 铝合金锭 / 棒材
铝锭棒材成分与外观检验
⌄
检验对象：压铸铝锭 / 棒材（牌号 ADC12，对应国标 YL112）。
核对内容：材质证明书（化学成分 Si 9.6~12%、Cu 1.5~3.5%、Mg≤0.3% 等）、外观（无裂纹/夹杂/油污）、批次追溯码。
为什么是地基：压铸铝的成分偏差会直接导致压铸件气孔、冷隔——后面 13 道工序都救不回。
2
压铸 ★ Die Casting · 伊之密 T160 · 0.05mm · 良率 90% · 10k/台/日
1600kN 冷室压铸成型镜筒毛坯
⌄
设备：伊之密 T160 冷室压铸机（锁模力 1600kN 级）。
工艺：铝合金熔炼（720±20℃）→ 高速注射（射速 2~3m/s）→ 保压（80~120MPa）→ 冷却开模 → 去水口 / 切边。
精度：0.05 mm（毛坯级，决定后道机加工的加工余量分配）。
关键控制点：模温（180~240℃）、铝液温度、保压时间——任一偏差直接产生气孔、冷隔、粘模，良率从 90% 跌到 60% 以下。
为何 ★：毛坯质量决定后 12 道工序成本和良率，毛坯废了整批报废。
3
脱硅 De-siliconizing · 手动线 · 良率 100% · 10k/台/日
NaOH 浸泡刷洗富 Si 层
⌄
工艺：化学法去除压铸件表面富 Si 层（ADC12 含 Si 9.6~12%，压铸时 Si 易在表面偏聚形成硬脆层，影响后续加工与阳极氧化色差）。
介质：NaOH 弱碱溶液（5~10%）浸泡 + 刷洗。
为什么不算关键：工艺成熟，失效模式单一（漏抛），靠人工全检可拦截。
4
CNC 铣 ★ CNC Milling · 兄弟 S500x1 · ±0.01mm · 良率 99% · 1000/台/日
立式主轴 + 旋转刀，X / Y 走刀
⌄
设备：Brother（兄弟）S500x1 立式加工中心。
加工内容：外形铣削（外形基准面 / 安装面 / 铭牌面）、槽 / 孔粗加工、基准销孔。
精度：±0.01 mm（外形尺寸 + 位置度）。
关键控制点：装夹方式（三爪 / 专用夹具）、刀具补偿（避免铝合金粘刀）、切削参数（转速 / 进给）——直接影响 0.01mm 精度的达成与刀具寿命。
为何 ★：外形基准是后道所有加工的定位基准，基准错了 = 整批系统性偏心。
5
CNC 车 1 ★ CNC Turning 1 · 北村 XKNC-204 · 0.002mm · 良率 95% · 500/台/日
镗内孔，保证光路同轴度
⌄
设备：北村（Kitamura）XKNC-204 走心机 / 数控车床。
加工内容：镜筒内孔（光学件装入的镜面级镜孔），镗孔 + 铰孔 + 滚压。
精度：0.002 mm（镜面级，与镜筒同轴度、圆度、镜面孔径粗糙度 Ra 强相关）。
关键控制点：主轴跳动（≤0.001mm）、刀具磨损补偿（每 50 件测量一次）、冷却液温度（±2℃）——0.002mm 是该设备极限，任何漂移即超差。
为何 ★：镜筒镜面孔是镜片定位基准，直接决定总装的 偏心 ≤0.3° 与 MTF。
6
CNC 车 2 ★ CNC Turning 2 · 北村 XKNC-204 · 0.002mm · 良率 95% · 600/台/日
车外形与端面，保证装配尺寸
⌄
加工内容：镜筒外圆 / 端面 / 螺纹 / 卡口结构精车。
精度：0.002 mm（与车 1 同级，但保证内/外圆同轴）。
关键控制点：一次装夹完成内/外/端面（避免二次装夹误差）、量具在线测量（车间三坐标抽检 5%）。
为何 ★：外圆 / 端面 / 螺纹配合是镜头卡口 / 密封圈 / 防护罩的装配基准，决定车载振动/防水/防尘等级。
7
喷砂 Sandblasting · 黔丰 QFH9070 · 良率 99% · 10k/台/日
金刚砂高速喷射，得到亚光面
⌄
设备：黔丰 QFH9070 自动喷砂机。
工艺：玻璃珠 / 棕刚玉砂对铝表面高速喷射，形成均匀的亚光（磨砂）底面，提升后续阳极氧化的色差均匀性与膜层附着力。
为什么不算关键：工艺宽容度大，砂粒粗细 / 气压偏差对最终外观的影响可被下道阳极氧化覆盖。
8
阳极氧化 ★ Anodizing · 手动线 · 0.002mm（膜厚均匀性） · 良率 98% · 10k/台/日
电解生成 Al₂O₃ 亚光发黑层
⌄
工艺：硫酸阳极氧化（电压 15~18V，电流密度 1.5 A/dm²，槽液温度 18~22℃）。在铝表面生成 Al₂O₃ 氧化膜（厚 5~15μm，硬 300~400HV）。
精度含义：0.002 mm 是整批膜厚一致性（决定外观色差与防护寿命）。
关键控制点：槽液温度（±1℃）、电流密度稳定、搅拌均匀、封孔质量（镍 / 钴封孔或热水封孔）。
为何 ★：对应 FCT-PFD 中"亚光发黑层 5–15μm、1000h UV 不变色、60°光泽≤2GU、孔隙率≤2.5%"——膜层质量直接决定车载户外耐候性与杂光控制（内壁光洁度差会反射生杂光）。
9
去除氧化层 ★ De-oxidizing · 兄弟 S500x1 · ±0.01mm · 良率 95% · 800/台/日
精铣配合面，露出铝基体
⌄
工艺：CNC 精密加工去除装配配合面的氧化膜，露出铝基体（保证导电 / 接地的电阻 ≤5Ω，对应 FCT-PFD 镜筒要求）。
精度：±0.01 mm（必须精确到只去配合面、保留内壁氧化层，多去 1μm 即破坏外观与防锈）。
关键控制点：刀路规划（避免干涉到内壁）、深度补偿、加工后电阻 100% 在线测试。
为何 ★：对应 FCT-PFD"镭雕+铬酸盐钝化、电阻≤5Ω、孔隙率≤2.5%"的接地需求——电阻超 5Ω 镜头在 EMC 测试中可能出干扰问题。
10
清洗 Cleaning · 手动线 · 良率 98% · 10k/台/日
纯水超声，去除切削液
⌄
工艺：超声清洗（去切削液 / 抛光膏残留）→ 纯水漂洗 → 干燥。
为什么不算关键：清洗不彻底主要影响外观，下道镭雕可全检筛除。
11
镭雕 ★ Laser Marking · 大鹏 · ±0.05mm · 良率 99% · 1000/台/日
底部激光烧码，PPAP 追溯
⌄
设备：大鹏光纤激光打标机。
雕刻内容：追溯码（生产日期 / 批次 / 设备号 / 炉号）+ 客户 logo + 物料编码（每个镜筒全生命周期可追溯）。
精度：±0.05 mm（决定追溯码在质检 OCR 系统的可读率）。
关键控制点：激光功率（避免烧穿氧化层露出白铝）、焦距（保证字符深度一致）、追溯码唯一性（系统级防重）。
为何 ★：追溯码是 PPAP 强制项（FCT-PFD 中 PSC 标识），客户召回 / 客诉时10 分钟内定位到具体炉号 / 设备 / 班次——丢了就召回不到具体件。
12
钝化 Passivation · 手动线 · 良率 98% · 10k/台/日
铬酸盐浸泡，稳定电阻
⌄
工艺：铬酸盐钝化（Cr³⁺ 环保型），在已去除氧化层的配合面生成 0.5~1μm 钝化膜，防接触腐蚀 / 提升导电稳定性。
为什么不算关键：工艺成熟，膜厚通过后续电阻测试可一次性筛选。
13
检验入库 Final Inspection & Warehousing
尺寸 / 外观 / 扫码最终放行
⌄
检验内容：全检尺寸（关键 5 项：外径、内孔、端面平面度、垂直度、粗糙度 Ra）+ 全检外观（氧化层色差、追溯码可读）+ 抽检性能（同轴度 0.005mm / 电阻 ≤5Ω）。
入库：合格件装防静电袋 → 周转库 → 下游 镜头总装（FZ010–FZ050 镜筒加工段的下一棒）。
为什么不入关键：检验本身是拦截，不是增值。问题在加工端，检验只是把关。
镜筒加工 vs 镜头总装：上游决定下游
镜筒是总装的上游，镜筒的 7 道关键控制工序决定了总装能不能达标：
工序 2 压铸 / 工序 5/6 CNC 车 → 决定 镜筒同轴度 / 圆度 → 总装偏心 ≤0.3°
工序 8 阳极氧化 → 决定 内壁光洁度 → 总装杂光 / VGI < 2.0%
工序 9 去氧化层 + 12 钝化 → 决定 电阻 ≤5Ω → 镜头EMC 测试能否通过
工序 11 镭雕 → 决定追溯体系 → PPAP 强制项 / 客诉召回能力
镜筒加工做好了，总装才有底气说 MTF / 场曲 / 畸变 / 杂光 / 偏心 / VGI 一次过。
